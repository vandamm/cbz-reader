- Acorn parsed all runtime scripts and the bundled JSZip distribution using `ecmaVersion: 5`: **passed**. This establishes syntax compatibility, not Safari engine behavior.
- Portrait library and landscape reader screenshots were visually inspected. The reader fits the whole page on black; controls can be hidden. Screenshots are generated by the optional browser test.
